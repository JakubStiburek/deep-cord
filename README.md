# deep-cord

*Project is no longer active.*

DeepCord was an idea that I've explored in the beginning of 2025. The main goal was to provide a platform for linguists and other scientists that work with audio recordings of speech. DeepCord should provide automatic trancription, analysis and annotations. The API portion of this prototype has one feature complete - user is able to upload an audio recording and get transcript with a few annotation types. Frontend portion for the feature is not finished.
